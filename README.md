# BrightBase

A cleaning operations platform developed around the workflows of The Maine Cleaning Company: client intake, quotes, scheduling, dispatch, invoicing, and communication.

## Why I built it

Running a service business requires moving information reliably between the website, customers, calendars, and the team. I developed and iterated on BrightBase to connect these workflows around real operational needs.

## My contribution

Business requirements and workflow design, AI-assisted implementation, interface iteration, platform configuration, feature testing, debugging, and deployment work.

## Workflow

Website intake → client and quote records → scheduled work and dispatch → invoicing and follow-up.

The source and project documentation also cover recurring jobs, turnover calendars, crew operations, and communication integrations.

## Stack

- Backend: Python, FastAPI, SQLAlchemy, Alembic
- Frontend: React and Vite
- Data: PostgreSQL
- Deployment configuration: Docker and Railway

## Status

Under active development and iteration. Feature and integration availability varies by deployment. This repository is not an invitation to access operational customer or employee records.
